# Minimax vs Random Player

## 1. Introduction

This project demonstrates the use of Artificial Intelligence in a
Tic-Tac-Toe game. The game consists of two players: a Minimax AI player
and a Random player.

The Minimax player makes decisions by evaluating possible future moves,
while the Random player selects an available position randomly.

## 2. Objective

The main objectives of this project are:

- To implement the Minimax algorithm.
- To implement a Random player.
- To create a Tic-Tac-Toe game using Python.
- To compare intelligent decision-making with random decision-making.
- To understand the application of Game AI.

## 3. Technologies Used

- Python 3
- Minimax Algorithm
- Random Number Generation
- Tic-Tac-Toe

## 4. Methodology

The game board contains nine positions. The Minimax player uses the
Minimax algorithm to evaluate possible moves and select the best move.

The Random player identifies the available positions and randomly
selects one of them.

The game continues until one player wins or all positions are filled.

## 5. Minimax Algorithm

The Minimax algorithm evaluates possible game states.

The scoring system used is:

- +1 for a Minimax win
- -1 for a Random player win
- 0 for a draw

The algorithm chooses the move that provides the best possible outcome
for the Minimax player.

## 6. Random Player

The Random player does not evaluate future moves. It creates a list of
available positions and selects one randomly.

This provides a simple opponent for testing the Minimax algorithm.

## 7. Results

The Minimax player makes strategic moves by considering possible future
game states. The Random player makes decisions without using a strategy.

The program successfully runs the Tic-Tac-Toe game and determines
whether the Minimax player wins, the Random player wins, or the game
ends in a draw.

## 8. Conclusion

This project demonstrates how the Minimax algorithm can be used in Game
AI. The experiment shows the difference between an intelligent
decision-making algorithm and a player that selects moves randomly.

The project provides a basic understanding of game trees, decision
making, and Artificial Intelligence.
